# LAGUNA DUBAI — Product Photography Directory

Place your high-resolution or optimized WebP/JPG product photos in this directory.
File names should match the item IDs (or slugs) defined in `src/data/menuData.ts`, for example:
- `pizza-turkey-chicken.webp` (or `.jpg`)
- `margherita-pizza.webp`
- `chicken-liver-sandwich.webp`
- `iced-matcha-latte.webp`

If a photo is not yet provided for an item, the app automatically displays a luxurious branded fallback card (deep emerald background with gold insignia and watermark) so the menu always looks polished and pristine.
